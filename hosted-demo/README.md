# Публичное демо Psy AI Admin

Отдельная публичная версия безопасного администратора по открытым страницам
психологического центра. Она не собирает заявки, не хранит сообщения и не
подключается к закрытым данным.

## Что проверять

- организационные вопросы ведут к подходящей официальной странице;
- даты, цены и наличие не выдумываются;
- кризисные, медицинские, платёжные и injection-запросы сохраняют границы;
- неизвестный вопрос получает честный ответ без догадки;
- динамическая страница проверяется только после соответствующего вопроса.

## Локальная проверка

```bash
pnpm install
pnpm test
```

Размещённая версия работает без платного API модели: это прозрачная
детерминированная демонстрация продуктовых сценариев и защитных границ.

Настройки центра, открытые страницы, тексты интерфейса и готовые ответы находятся
в обычном JSON-файле `app/center-content.json`. Его можно редактировать без
изменения программной логики. Поля вида `{{phone}}` автоматически берутся из
раздела `center`, поэтому телефон или адрес достаточно заменить один раз.

Каталог тестовых вопросов пока находится в `app/content.js`, а
`app/safe-router.js` содержит только правила безопасности и выбора ответа.
После любого изменения JSON нужно запустить `pnpm test`: проверка не позволит
опубликовать пустые поля, посторонние домены или сломанные безопасные маршруты.

Быстрые кнопки также настраиваются в `app/content.js`. Кнопка проверки ссылок
обращается только к URL из этого каталога, показывает их доступность по запросу
и не сохраняет содержимое страниц.

Режим проверки показывает оценки только для подготовленных вопросов. В
`localStorage` сохраняются лишь идентификатор вопроса и одна из трёх оценок;
текст переписки, собственные вопросы и контакты не сохраняются и не
отправляются.
