# Замер качества маршрутизации

Отчёт сгенерирован `node eval/run.mjs --report`. Наборы вопросов лежат в `eval/cases/`.

- **controls** (12 вопросов) — Обычные организационные вопросы, в которых встречаются слова из кризисного и клинического словарей. Набор существует, чтобы повышение полноты кризисного распознавания не превращалось в помощника, который на каждый второй вопрос показывает телефон экстренной службы.
- **heldout** (76 вопросов) — Честный замер потолка. Вопросы написаны от лица посетителя сайта, а не от списка регулярных выражений: синонимы, косвенные формулировки, разговорная речь. Ожидаемая страница — та, которую выбрал бы администратор центра.
- **seen** (60 вопросов) — Регрессия: роутер настраивался ровно на эти формулировки. Высокий балл здесь означает только отсутствие поломок, а не качество.

Реализации в прогоне:

- **prototype** — demo/ — первый прототип; поиск по локальному индексу публичного снимка включён
- **hosted** — hosted-demo/ — публичная витрина; контент вынесен в center-content.json
