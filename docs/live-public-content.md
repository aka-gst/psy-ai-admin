# Актуальные публичные данные по запросу

> Документ описывает механизм заархивированного прототипа (`server.py`, тег
> `archive/prototype-v1`). В витрине его заменяет проверка доступности ссылок
> `/api/health`, которая не сохраняет содержимое страниц. Требования
> безопасности ниже остаются в силе для любой будущей реализации.

Для динамических разделов демо не полагается только на локальный снимок.
После вопроса о расписании, клубе или аренде локальный сервер запрашивает
соответствующую открытую страницу и показывает фрагмент свежего текста рядом с
кнопкой перехода.

## Ограничения безопасности

- Разрешены только три URL из `LIVE_PAGES` в `server.py`.
- URL не принимается от посетителя, редиректы и закрытые разделы не обходятся.
- Ответ сервера имеет `Cache-Control: no-store`; текст страницы не записывается
  в файлы, Git, логи приложения или историю чата.
- При недоступности страницы демо сохраняет безопасный вариант: карточку
  перехода на официальный сайт без неподтверждённого факта.

До интеграции с реальным сайтом список URL, частота запросов и формат передачи
заявки должны быть согласованы с владельцем центра.
