# Локальный снимок публичного сайта для тестирования

Снимок открытого сайта `orion-center.ru` сохраняется локально в
`reference/orion-center-public-snapshot/` и намеренно исключён из Git. Это
внешний контент, а не часть продукта и не подтверждённая база знаний.

Дата захвата: 18 августа 2026. Снимок включает HTML следующих публичных
маршрутов: главная, расписание, клуб, ProcessWork, консультации, аренда,
программы и `robots.txt`.

## Допустимое использование

- Сравнение навигации, текстовой структуры и ссылок при разработке демо.
- Ручные сценарии без ввода персональных, платёжных или медицинских данных.
- Проверка, что помощник направляет на корректную публичную страницу.

## Ограничения

- Не открывать и не использовать снимок как рабочую форму записи, оплаты или
  личного кабинета: HTML может содержать внешние ссылки и формы.
- Не публиковать, не включать в релиз и не коммитить этот снимок без отдельного
  письменного разрешения правообладателя.
- Не считать снимок актуальным источником: для каждого факта в продукте нужен
  свежий утверждённый URL и дата проверки.
- Не скачивать закрытые страницы, результаты отправки форм, личный кабинет,
  платёжные страницы и аналитику.
