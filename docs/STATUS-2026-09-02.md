# Передача состояния: Psy Admin

## Принято — не менять

Боевой адрес: `https://aka-gst.ru/psy-admin/`.

Эталон — полноценная копия первого экрана «Орион-С»: метка «ПСИХОЛОГИЧЕСКИЙ
ЦЕНТР · ОРИОН-С», заголовок «Пространство для изменений», карточка «Найти
подходящий формат» и AI-администратор поверх страницы справа. Упрощённый
отдельный экран или один виджет без этой страницы не является заменой.

## Текущее состояние

- Ветка этого репозитория: `codex/v2-booking`, голосовой контур — commit
  `68c56db`.
- Голос: ручной тап микрофона, распознавание на русском, озвучка только ответа
  на голосовой вопрос; текстовые вопросы не озвучиваются.
- На отсутствии API или отказе микрофона текстовый ввод остаётся доступным и
  показывает понятное сообщение.
- На бою содержимое страницы и виджета сверено 2 сентября 2026: hero и карточка
  совпадают с принятым экраном; в `psy-widget.js` есть кнопка микрофона,
  `SpeechRecognition`/`webkitSpeechRecognition` и `SpeechSynthesisUtterance`.

## Проверки и граница

- `npm test`: 28/28.
- В браузере на ширине 390px проверены кнопка микрофона, fallback при запрете
  доступа и текстовый ответ со ссылкой.
- Реальное распознавание и слышимая речь на боевом сайте не проверены: тестовый
  браузер не предоставил доступ к микрофону. Это следующий точечный приёмочный
  шаг, без изменения кода.
