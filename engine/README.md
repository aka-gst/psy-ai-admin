# Движок безопасного администратора

Одна реализация обслуживает и публичную витрину (`hosted-demo/`), и серверный
продукт с реальной записью (`v2/`). Правило безопасности, добавленное здесь,
действует в обоих сразу — ради этого движок и выделен.

Зависимостей нет: чистый ESM на встроенных модулях Node.

## Использование

```js
import { createAssistant } from "../engine/index.mjs";

const assistant = createAssistant(catalog);
assistant.ask("Какие мероприятия ближайшие?");
// { text: "…", sourceKeys: ["schedule"], kind: "route" }
```

`ask(question, lastSourceKey)` — второй аргумент нужен для коротких уточнений
(«она онлайн или очно?»), которые продолжают предыдущую тему.

## Что принадлежит движку, а что арендатору

| Движок | Каталог арендатора |
|---|---|
| распознавание кризисных сообщений | текст кризисного ответа |
| распознавание медицинских, платёжных и обходных запросов | страница, куда вести после отказа |
| порядок «сначала безопасность, потом темы» | список тем и их регулярные выражения |
| проверка каталога до первого вопроса | контакты, подписи ссылок, все тексты |

Разделение не косметическое: владелец сайта редактирует JSON и не может
случайно ослабить границу. Попытка перехватить кризисное сообщение своим
правилом не сработает — кризис проверяется первым, и это закреплено тестом.

## Каталог

```jsonc
{
  "center":    { "name": "…", "emergencyNumber": "112" },   // подстановка {{name}} в тексты
  "sources":   { "home": { "label": "…", "url": "https://…" } },
  "responses": { "crisis": "…", "unknown": "…" },
  "pipeline":  [ { "safety": "crisis" }, { "match": "распис|когда", "response": "schedule", "sources": ["schedule"] } ],
  "fallback":  { "response": "unknown", "sources": ["home"], "kind": "unknown" },
  "empty":     { "response": "empty", "sources": [], "kind": "route" }
}
```

Шаги `pipeline` проверяются по порядку, побеждает первый совпавший. Шаг бывает
четырёх видов: `safety` (обнаружение внутри движка), `match` (регулярное
выражение арендатора), `followUp` (продолжение предыдущей темы) и `search`
(поиск по документам).

`url` источника — либо `https`-адрес, либо путь на своём сайте (`/`), чтобы
помощник внутри продукта вёл к собственной форме, а не наружу.

## Поиск по документам

Шаг `{ "search": true, "minScore": 3 }` включает BM25 по описаниям страниц.
Корпус собирается из поля `about` каждого источника, а при необходимости
дополняется разделом `documents` каталога. Источник с описанием обязан указать
`response` — ответ, которым помощник отвечает, когда поиск выбрал эту страницу.
Ниже `minScore` поиск возвращает отказ, и помощник признаёт незнание.

Раздел `faq` каталога добавляет к корпусу ответы на вопросы, которых нет на
страницах. Запись с `confirmed: false` участвует в поиске, но её текст не
произносится: помощник отвечает обычным текстом найденной страницы. Так
требование «не выдавать неподтверждённое как достоверное» держится кодом, а не
дисциплиной редактора.

Снять флаг молча тоже нельзя: запись с `confirmed: true` обязана назвать
`confirmedOn` (дата в виде `ГГГГ-ММ-ДД`) и `confirmedBy` (от кого получено
подтверждение). Без них каталог не запускается. Лист для подтверждения —
[`docs/faq-confirmation.md`](../docs/faq-confirmation.md).

Замеры: на одних правилах независимый набор давал 21 из 39, с FAQ и поиском —
31 из 39 при одной дополнительной ошибке. До появления FAQ тот же поиск был
убыточен. Разбор — [`docs/retrieval-experiment.md`](../docs/retrieval-experiment.md).

## Проверки, без которых каталог не запустится

- первый шаг `pipeline` — `{ "safety": "crisis" }`;
- присутствуют шаги `injection`, `payment`, `clinical`;
- каждый упомянутый ответ и источник существует;
- адрес источника — `https` или путь своего сайта;
- кризисный ответ не предлагает переходов, даже если каталог их указал.

Ошибка в каталоге обнаруживается при запуске, а не на живом посетителе.

## Границы безопасности

Списки сигналов лежат в [`safety-signals.mjs`](safety-signals.mjs) и намеренно
не выносятся в каталог. Кризисный набор настроен на полноту, а не на точность;
цена этого выбора удерживается контрольным набором вопросов в
[`eval/cases/controls.json`](../eval/cases/controls.json).

Одинаковое поведение границ у всех арендаторов проверяется тестом
«границы безопасности одинаковы для всех арендаторов» в `eval/eval.test.mjs`.
