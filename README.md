# Psy AI Admin

Безопасный AI-администратор для сайта психологического центра.

Первый кандидат для пилота — центр «Орион-С»: <https://orion-center.ru/>.
Это независимый учебно-коммерческий проект, не связанный с центром и не
использующий его закрытые данные без письменного разрешения.

## Задача продукта

Помочь посетителю сайта:

- разобраться в услугах, специалистах и программах;
- найти актуальное расписание, формат, стоимость и адрес;
- перейти на подходящую страницу;
- оставить заявку администратору;
- получить понятный ответ только из утверждённой базы знаний.

Помощник не является психологом, не ставит диагнозы, не проводит терапию,
не назначает лечение и не заменяет экстренную помощь.

## Первый MVP

1. Чат на отдельной демонстрационной странице.
2. RAG по публичным материалам центра с указанием источников.
3. Сценарии: выбор направления, специалиста, мероприятия и способа записи.
4. Безопасный отказ от диагностики и терапевтических советов.
5. Передача диалога человеку и сбор минимальной заявки только с согласием.
6. Журнал вопросов без сохранения чувствительных подробностей.

## Критерии готовности пилота

- не менее 30 проверочных вопросов;
- каждый фактический ответ содержит ссылку на источник;
- устаревшая или противоречивая информация не выдаётся как достоверная;
- кризисные сообщения переводятся в безопасный сценарий;
- персональные данные не попадают в Git и логи модели;
- владелец центра может исправить базу знаний без изменения кода.

Подробный маршрут: [ROADMAP.md](ROADMAP.md).

## Локальное демо этапа 2

Демо находится в `demo/`. Оно намеренно не подключается к сайту центра, не
отправляет заявки, не хранит сообщения и не обращается к закрытым данным.
Маршрутизатор ограничивает ответы утверждёнными публичными URL и отказывает в
диагностике, терапии, медицинских советах, платёжных и кабинетных данных.

Для локального просмотра с проверкой динамических страниц по запросу:
`python3 server.py`, затем откройте `http://127.0.0.1:4173`. Для проверки
защитных сценариев: `npm test`.

Перед первым открытием демо после скачивания снимка создайте локальный индекс:
`python3 scripts/build-public-index.py`. Индекс не коммитится: он производный
артефакт из открытого снимка сайта.

Динамические разделы (расписание, клуб, аренда) демо запрашивает только после
вопроса пользователя. Сервер разрешает ровно три публичных URL, не хранит
полученный текст и отдаёт ответ без кэширования.

Справочный снимок публичных HTML-страниц для тестов описан в
[`docs/public-snapshot.md`](docs/public-snapshot.md). Он локальный, исключён из
Git и не является частью демо или базы знаний.

Черновик коммерческого предложения для первого платного этапа:
[`docs/pilot-offer-15000.md`](docs/pilot-offer-15000.md).
