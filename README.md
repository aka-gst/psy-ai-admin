# Публичное демо Psy AI Admin

Отдельная публичная версия безопасного администратора по открытым страницам
психологического центра. Она не собирает заявки, не хранит сообщения и не
подключается к закрытым данным.

## Что проверять

- организационные вопросы ведут к подходящей официальной странице;
- даты, цены и наличие не выдумываются;
- кризисные, медицинские, платёжные и injection-запросы сохраняют границы;
- неизвестный вопрос получает честный ответ без догадки;
- динамическая страница проверяется только после соответствующего вопроса.

## Локальная проверка

```bash
pnpm install
pnpm test
```

Размещённая версия работает без платного API модели: это прозрачная
детерминированная демонстрация продуктовых сценариев и защитных границ.

Открытые страницы и каталог готовых тестовых вопросов находятся в
`app/content.js`. При адаптации под следующий центр сначала меняется этот
файл, затем обновляются и прогоняются проверки маршрутов.
